# Mascot

Nudge's mascot is an original character drawn in code for this app: a round,
chunky sprout with a solid lip under its body (like the app's buttons), two
feet, big eyes and a two-leaf sprout.

`idle.json` (breathing, sprout sway, a blink; 3s loop) and `cheer.json` (a
squash-and-stretch jump with happy eyes; 1.5s loop) are Lottie files
generated by `tool/mascot/mascot.py`, which also renders the app icon in
`assets/icon/`. Edit the generator and re-run it; don't hand-edit the JSON.
The app recolours the `Body`, `Lip`, `Feet` and `Sprout` layers to the active
palette, so keep those layer names.
