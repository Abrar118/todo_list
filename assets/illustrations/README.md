# Illustrations

(<https://github.com/microsoft/fluentui-emoji>), MIT licensed — see
`FLUENT-EMOJI-LICENSE.txt` beside this file. Each file is the set's `3D`
variant at 256×256, unmodified, renamed to its slug:

They are illustrations — stat tiles, empty states, the hero card — never a
substitute for the icon set, which stays Material/Cupertino icons. A custom
Nudge mascot would replace these once real artwork exists.

The UI font is **Nunito** (`assets/fonts/`, SIL Open Font License 1.1 — see
`assets/fonts/Nunito-OFL.txt`), static instances downloaded from Google Fonts.
